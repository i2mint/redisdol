Bases: RedisBytesReader, KvPersister

Provides a collections.abc.MutableMapping (i.e. dict-like) interface to Redis.

Note that Redis automatically converts everything to bytes when writing, which means that read and write are not inverse of each other in the base RedisPersister. A serialization/deserialization layer can be added to make read and write consistent.

Note

You need to have a redis server running (on the port chosen by default by RedisBytesPersister, etc.) to perform the following:

>>> s = RedisBytesPersister()  # plenty of params possible (all those of redis.Redis), but taking defaults.
>>>
>>> # clear the kehys we'll be using
>>> keys = ['_pyst_test_str', '_pyst_test_int', '_pyst_test_float']
>>> for k in keys:
...     del s[k]
>>>
>>> before_length = len(s)
>>>
>>> s['_pyst_test_str'] = 'hello'
>>> s['_pyst_test_str']  # note you won't be getting a str but bytes
b'hello'
>>>
>>> '_pyst_test_str' in s
True
>>>
>>> # numbers are converted to strings then bytes
>>> s['_pyst_test_int'] = 42
>>> assert s['_pyst_test_int'] == b'42'
>>> s['_pyst_test_float'] = 3.14
>>> assert s['_pyst_test_float'] == b'3.14'
>>>
>>> assert len(s) == before_length + 3
>>>
>>> assert '_pyst_test_float' in s
>>>
>>> # clean up
>>> for k in keys:
...     del s[k]
>>>

class redisdol.base.RedisFactories[source]#

Bases: object

Classmethod constructors that reuse an existing Redis connection.

Kept for backward compatibility, but the store classes no longer inherit it: a classmethod on a store’s attribute surface is re-exported leaf-bound by every dol wrapper (key codec, prefix, filter…), so it hands back an unwrapped store over the whole keyspace. Prefer the module-level store_from_source() / store_from_sourced_object().

class redisdol.base.RedisList(source, name, *, encode=None, decode=None)[source]#

Bases: MutableSequence

An object to operate on Redis lists as if they were python lists

A live handle: writes go straight to Redis. It is raw (no codec) unless encode / decode are given, in which case encode is applied to every element written (__setitem__, append, extend) and decode to every element read. A codec layered on the store (e.g. wrap_kvs) cannot reach into a handle it returns, so pass the element codec here (see RedisCollection.list_encode / list_decode).

>>> from fakeredis import FakeRedis
>>> l = RedisList(FakeRedis(), 'l', encode=str.upper, decode=bytes.decode)
>>> l.extend(['a', 'b']); l.append('c'); l[0] = 'z'
>>> list(l)
['Z', 'B', 'C']

insert(i, v)[source]#

Insert v before position i (list.insert semantics: i is clamped).

LINSERT is relative to a value (wrong with duplicates), so the element currently at the target position is temporarily replaced by a unique sentinel, v is inserted before it, and the original is put back. This runs in a WATCH/MULTI transaction (retried if the list changes meanwhile).

redisdol.base.store_from_source(source, cls=None)[source]#

Make a store of type cls (default RedisPersister) over a Redis connection.

The returned store is a plain cls instance: it sees the whole keyspace of source. Apply any key/value codecs to the result yourself. cls may be a class already wrapped with dol (e.g. RedisStoreWithNumericLists): its wrapped class is built over source and wrapped as usual.

>>> from fakeredis import FakeRedis
>>> s = store_from_source(FakeRedis())
>>> s['k'] = 'v'
>>> s['k']
b'v'
